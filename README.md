# Middagsplan og handleliste

Ukeplan for middager og handleliste for to, med felles lagring i et Google-regneark.

- **Uke:** foreslår en uke etter fast rytme (fisk mandag og torsdag, vegetar onsdag, kos på fredag, lengre retter i helgen, maks 30 minutter på hverdager). Samme rett kommer ikke igjen innen tre uker, og ferskvarer gjenbrukes der det går.
- **Handleliste:** samler ingrediensene, slår sammen like varer og sorterer etter butikkavdeling. Månedsmodus deler lista i det som kan kjøpes nå (holdbart og til fryseren) og ferskvarer uke for uke.
- **Middager:** en startbank med vanlige norske hverdagsretter. Dere kan legge til egne, merke favoritter og velge bort retter.

Planen lagres i nettleseren og, når den er koblet til, i et Google-regneark via et lite Apps Script (`apps-script/Kode.gs`). Siden inneholder ingen data selv.
